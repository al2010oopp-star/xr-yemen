مشروع التواصل اليمني - نسخة بداية تجريبية

مهم:
- هذا مشروع مصدر لأندرويد، وليس ملف APK جاهزاً للتثبيت.
- الواجهة الحالية نموذج أولي يعرض قائمة محادثات وإعدادات شكلية.
- لا يوجد حتى الآن تسجيل برقم الهاتف أو إرسال رسائل حقيقية أو مكالمات أو تشفير أو قفل بصمة فعّال.
- لا تستخدمه للتواصل الحقيقي أو لتخزين معلومات خاصة.

فتح المشروع:
1) انقل الملف المضغوط إلى كمبيوتر.
2) ثبّت Android Studio وافتحه.
3) اختر Open ثم اختر مجلد YemeniMessenger بعد فك ضغط الملف.
4) انتظر مزامنة Gradle، ثم اختر Run لتجربته على هاتف متصل أو محاكي.

المتطلبات:
- Android Studio حديث
- Android SDK 35
- اتصال إنترنت أول مرة لتنزيل أدوات البناء

الخطوة التالية في التطوير:
إضافة تسجيل آمن برقم الهاتف، وخادم وقاعدة بيانات، ومحادثات حقيقية، ثم المكالمات الصوتية والخصوصية.
